ARQUIVOS
- index.html: conteúdo e estrutura do site.
- styles.css: visual, cores e layout responsivo.
- script.js: galeria de projetos.
- assets/logo-ds-guiomar.png: logotipo.

PUBLICAÇÃO
Envie a pasta inteira para a hospedagem, mantendo a estrutura. O arquivo inicial é index.html.
O site é estático: não precisa de backend, banco de dados ou dependências.

COMO ADICIONAR PROJETOS
1. Copie a foto para a pasta assets/.
2. Abra script.js e localize a lista `projects`.
3. Adicione um objeto neste formato:

{
  title: "Nome do projeto",
  category: "Robótica",
  description: "Uma frase contando o que os estudantes criaram.",
  image: "assets/foto-do-projeto.jpg"
}

Para adicionar mais projetos, separe os objetos por vírgula.
